# Security

This offline tool needs no API keys or credentials. Do not commit private observations, tokens or confidential source material. Reports repeat input data and should be stored with appropriate access controls.

Report suspected vulnerabilities privately through GitHub's private vulnerability reporting feature when available. If unavailable, open an issue requesting a private reporting route without including exploit details, secrets or personal data. Include the affected version and a minimal fictional reproduction when a private channel is established.

Treat input and output as untrusted data. HTML escapes supplied content, and CSV neutralizes formula prefixes; JSON preserves raw values and needs destination-specific encoding in downstream tools. Clicking source links leaves the offline report.
